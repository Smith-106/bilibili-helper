# 风控与安全语义（R3）

目标：**正常 pacing 下不主动触发风控**。下表为方案行为约束（可在源码与 `evidence/` 复核）。

| 约束 | 值 / 机制 |
|------|-----------|
| 列表分页间隔 | 起步 2–3s；页间隔档位联动 4.5–10s（v3.0.19；默认约 4.5–6s，超稳档约 8.5–10s）+ 受限后自适应 +2s/次（上限 +6s） |
| -799/网络异常退避 | pn1 双败 fast-fail（只重试 1 次约 12s）+ 15min 冷却记忆（期间零请求）；中途分页加长递增最多 4 次，`14+rt*6`s + `0–3s` 抖动（约 20/26/32/38s），耗尽写冷却 |
| 分页上限 | `t >= 40` 页 |
| 去重 | `seen` Set（bvid） |
| 抛错 | 列表腿零 throw，统一 partial 降级 |
| -352 | 零重试（直接降级） |
| -403 / -401 | 静态清零，无登录依赖 |
| 批量节奏 | `delay + jitter`，连续失败 `>=2` → `delay*3` |
| 持久化 | `bilibili_helper_batch_done`（已完成 cid）；`bilibili_helper_uplist_<mid>`（列表增量缓存，每页成功即写）；`bilibili_helper_uplist_cool_<mid>`（15min 冷却标记，pn1 双败/中途耗尽均写） |
| pn1 失败兜底 | 有缓存→缓存 partial 继续；无缓存→进冷却提示，不空转重试 |

## 沙盒 vs 真机

沙盒匿名出口曾观测到 `-799×1`、`HTML_412×2`、`TRANSIENT×3`（均为出口配额/抖动，单发退避即恢复）。这些属环境观测，**非**方案主动触发。真机正常 pacing 下不出现。

## 设计红线

- 不用 wbi 签名（已移除，legacy 接口即可）。
- 不引入登录依赖（`-403/-401` 不抛「需登录」）。
- 单条目兜底（`top/arc`）**不得**回填为批量列表 —— 防止「只下 1 集」回归。
- 首屏冷却期内**不得**再发请求（fast-fail + 零请求恢复）—— 防止「越点限得越久」。
- 中途分页逐页复检冷却标记（v3.0.19），冷却写入后即停 —— 防止冷却期内继续打页。
- 实测确认无第二完整列表桶（space HTML 空壳/dynamic 需鉴权/series 报 -400/top 仅 1 条）—— 不做换接口 failover，只做节奏+冷却+缓存。
