# 快速开始

## 安装（开发者模式）

1. `chrome://extensions`（Edge: `edge://extensions`）
2. 开启「开发人员模式」
3. 「加载已解压的扩展程序」→ 选择仓库根目录
4. 打开任意 `bilibili.com/video/...` 页面，底部出现「B站下载助手」面板

## 模式

- **高级模式**（默认）：自动重命名 + ffmpeg wasm 合并音视频，占用较大内存。
- **兼容模式**：浏览器默认下载，资源占用小，无重命名/合并。

## 清晰度

默认跟随播放器当前清晰度；面板可固定 qn（16/32/64/80/112/120/125）。

## 常见问题

- **解析失败 / 提示清除缓存**：清除 bilibili cookies 后重试。
- **批量中断**：已下载集数写入 `localStorage.bilibili_helper_batch_done`，勾选「跳过上次已下载」续跑。
- **-799 请求过于频繁**：属服务端配额，扩展自动递增退避（最多 4 次，最长约 27s）后继续；若持续受限返回部分列表，稍候再试。
