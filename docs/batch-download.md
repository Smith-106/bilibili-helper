# 批量下载指南

## 批量下载合集

在含 `ugc_season` 合集的视频页，点击 **「批量下载合集」**。扩展枚举合集全部集数并逐集下载。

## 批量下载 UP 主全部视频

在该 UP 主任一视频页点击 **「批量下载该UP主全部视频」**。

- 列表来源：`x/space/arc/search?mid=<mid>&pn=N&ps=30&order=pubdate`（legacy 接口，匿名可用，无 wbi 签名）。
- 每页 30 条，页间 1500–2300ms 随机间隔，最多 40 页。
- 按 `bvid` 去重收敛后进入下载循环。

### 速度档

| 档位 | 每集间隔 |
|------|----------|
| 快速 | ~1s |
| 标准 | ~3s（默认） |
| 保守 | ~6s |
| 最稳 | ~12s |

> 间隔 = `delay*1000 + random*delay*500`；连续失败 ≥2 自动提升到 `delay*3`。

### -799 处理（v3.0.17 起）

-799/网络异常 → 递增退避最多 4 次（约 12/16/20/24/27s）后继续分页；耗尽后返回 partial/空，**不再**退化为单条目批量。

### 断点续传

`bilibili_helper_batch_done` 持久化已完成 `cid`；勾选「跳过上次已下载」即可续跑。「清空记录」可重置。
